## 1. 결론
1. **Gem 사례 21건 중 14건이 유니콘·대기업입니다.** Gem이 해결하는 것은 "사내 TA팀의 생산성"입니다(분석 8건, 도구 통합 8건, 아웃리치 자동화 5건).
2. **해외·원격 관련 언급은 6건뿐**입니다(Celestica 3개국 채용, Carta 새 지역, Octave 원격 회사, Terminal 니어쇼어 공급사, Daxko·OneSignal 사기 탐지). **언어·학력 기준·노동법·시차를 다룬 사례는 0건**입니다.
3. 해외 원격 채용 Pain 11개 중 **Gem이 확실히 해결하는 것은 P4(사기 후보 탐지) 하나**입니다.
4. **P2(학력·자격·직급 기준 표준화), P5(해외 경력·학력 조회), P6(원격 근무 적합성)은 조사한 9개 솔루션 모두 공백**입니다. 원티드의 차별화 후보이지만, 원티드도 현재는 부분 대응 수준입니다.

## 4. 원티드의 차별화 프로세스 (제안 · 검증 전 가설)
"원격 채용의 불확실성을 줄이는" 8단계입니다.

| 단계 | 내용 | 해소하는 Pain |
|---|---|---|
| 1. 소싱 | 원티드 국내 풀(+일본 HR Booster)에서 언어 태그로 추출하고, 미국 고객용 영어 프로필 제공 | P1 |
| 2. 기준 표준화 | 학력·자격·직급을 미국 기준으로 환산한 등가표 첨부(예: 과장 ≈ Senior/Manager) | P2 |
| 3. 언어 3단 검증 | 공인 점수 확인 → 이중언어 인터뷰(영·한/영·일 롤플레이) → 영어로 직무 과제 제출 | P3 |
| 4. 신원·경력 검증 | 영상 신원 확인 + 본인 동의 기반 경력 증빙 + 학위 확인 | P4, P5 |
| 5. 원격 적합성 | 근무 가능 시간대, 비동기 협업 과제 | P6 |
| 6. 유급 트라이얼 | 1~2주 계약 업무 후 정규직 전환 | P7 |
| 7. 고용·보상 | EOR 연계, 현지 연봉 벤치마크, 노동법 가이드 | P8, P9 |
| 8. 보증·온보딩 | 대체 보증 + 30·60·90일 체크인 | P10 |

**주의**
- 4단계는 실무진 경고("경력 검증이 학력·해외 신원조회까지 되는 것처럼 표현하지 말 것")를 반영해서 검증 범위를 명확히 해야 합니다.
- 2·3단계의 기준·루브릭은 새로 설계해야 합니다.
- 6단계는 원티드 긱스와 연계할 수 있는지 확인이 필요합니다.
