## 2. AX 사업 (핵심 상세) ★

### 2-1. 사업 구조 요약

원티드랩 AX 사업은 **솔루션, 교육, 컨설팅·도입 지원, 패키지**의 네 층으로 이루어집니다.

```
[솔루션]   원티드 LaaS → 엔노이아(Ennoia) : 에이전트 개발·운영·통제 플랫폼
[교육]     원티드 프론티어즈 · AX 챌린지 · AI 프롬프톤(렛서와 공동) · 산학협력(숙명여대)
[도입지원] 프롬프톤 → PoC → 기업별 모델 개발·도입 / 온프레미스 구축
[패키지]   AX 통합 패키지 = 임직원 교육 + 사내 AI 환경 구축 + AI 기반 인재 관리
[내부검증] AX 챔피언(사내 8주 프로그램) → 외부 컨설팅 상품화 계획
```

### 2-3. 솔루션: 원티드 LaaS → 엔노이아(Ennoia)

**(1) 원티드 LaaS (LLM-as-a-Service), 리브랜딩 이전**
- 구독형 생성형 AI 개발 도구. "누구나 LLM을 하나의 완성된 서비스처럼 쉽게 사용"하도록 하는 것이 목표입니다.
- 회사 주장: **3일 안에 AI 서비스 개발 가능**
- 별도 가입 없이 여러 LLM 중에서 선택, 프롬프트 버전 관리, 사용량 모니터링 기능 제공
- 20종 이상 LLM, 멀티모달, RAG 지원, **최대 100명 동시 실습 환경** (교육용)
- Source: [CIO Korea, 3일만에 AI 서비스 개발 가능](https://www.cio.com/article/3507914/), [ITWorld, 원티드 LaaS](https://www.itworld.co.kr/article/3545785/), [디지털타임스, 렛서 MOU](https://www.dt.co.kr/article/11638439)

**(2) 엔노이아(Ennoia), 2026년 4월 리브랜딩·정식 출시**
- 원티드 LaaS의 이름을 바꿔 **기업용 통합 AX 플랫폼**으로 출시
- AI 에이전트의 **개발 → 운영 → 통제** 전 과정을 지원
- **온프레미스 구축** 가능: 고객사 자체 서버에 설치해 내부 데이터를 안전하게 관리
- **멀티 에이전트 운영 로그 통합 관리**: 보안과 거버넌스 요구에 대응
- **데이터 연동**: 사내 파일 서버, 협업 도구, 외부 DB 등 여러 데이터 소스를 연결해 실제 업무 흐름과 이어줌
- **SDK 제공**: 에이전틱 AI, RAG 등 최신 생성형 AI 기술을 SDK 형태로 제공
- **도입 현황**: 20여 개 기업·기관에서 엔노이아 기반 에이전트 약 700개 가동
- **고객 사례 (공개분)**: 한국고용정보원, 한국관광공사. 대기업 중심 사업이라 주요 수주는 모두 공개하기 어렵다고 대표가 밝혔습니다.
- **내부 검증 후 외부 확산**: 원티드랩 사내에서 먼저 검증한 뒤 대기업·공공기관으로 확대
- Source: [Venturesquare (EN), WantedLab Launches 'Ennoia'](https://www.venturesquare.net/en/1076193/), [Venturesquare 뉴스 모음](https://www.venturesquare.net/?p=1076136), [디지털투데이, LaaS → 엔노이아 리브랜딩](https://www.digitaltoday.co.kr/jp/view/47954/wantedlab-rebrands-wanted-laas-to-ennoia-to-target-company-wide-ax-market), [헤럴드코퍼레이션 (EN)](https://biz.heraldcorp.com/article/10796961), [헤럴드경제 (2026.07)](https://www.heraldk.com/article/2026070519344804935), [다음뉴스 동일 기사](https://v.daum.net/v/20260703094953522)

**용어**
- **온프레미스(On-premise)**: 클라우드가 아니라 고객사 내부 서버에 직접 설치하는 방식. 금융·공공처럼 보안 요구가 높은 곳에서 선호합니다.
- **RAG (Retrieval-Augmented Generation)**: AI가 답할 때 사내 문서 등 외부 지식을 검색해 근거로 쓰는 기술
- **에이전틱 AI / AI 에이전트**: 질문에 답만 하는 것을 넘어 스스로 도구를 쓰고 여러 단계의 업무를 수행하는 AI
- **SDK (Software Development Kit)**: 개발자가 기능을 붙여 쓸 수 있도록 제공하는 개발 도구 묶음
